# Seguridad del Admin

| Riesgo                                | Defensa                                                                                                                                                                             | Prueba                                                     |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| Publicación REAL accidental           | `PUBLICATION_ENABLED_FOR = ['FIXTURE']` intacto; sin botón REAL operativo; `publishFixtureCandidate` rechaza REAL antes de llamar a publish; `publishCandidate` lo rechaza de nuevo | `admin-safety` · `admin-boundaries` · E2E A                |
| Saltarse el formulario (POST directo) | Cada Server Action → handler con Zod estricto (claves extra rechazadas), actor obligatorio y capacidad; los servicios validan estado y dominio; triggers en la base                 | `admin-safety` (sin actor, claves extra, plan falsificado) |
| Defaults silenciosos                  | Nada se preselecciona; `null` nunca se vuelve `false`; alta de item exige estado y política explícitos; evidencia separada de las decisiones                                        | `admin-review` · `review.test` · E2E A/B/F                 |
| Lógica de dominio en la UI            | La UI recibe DTOs ya calculados (`unresolvedFields`, preview del adaptador, `resolvePrice`); `src/app` no importa pricing, adaptador, reglas de requisitos ni SQL                   | `admin-boundaries`                                         |
| Filtración de históricos              | Secciones separadas y etiquetadas; sin acciones; guard de 0012 (histórico ≠ fuente de PRICE); snapshot sólo AUTHORIZED/SUPERSEDED                                                   | `admin-pricing` · `import-staging` · E2E E                 |
| Mutaciones directas desde el cliente  | Componentes cliente sin `@/db`, `pg` ni handlers; sólo llaman Server Actions                                                                                                        | `admin-boundaries`                                         |
| Masivos destructivos                  | Vista previa obligatoria, conteos, distintos no se sobrescriben sin confirmar, plan con hash, bloqueo de filas, append-only, sin borrar                                             | `admin-bulk` · E2E D                                       |
| Identificadores editables             | `id`, `public_code` y `kind` fuera del esquema; triggers de 0001                                                                                                                    | `admin-catalog`                                            |
| Aprobación sin decisión completa      | `approveCandidate` exige cubrir campos abiertos; BLOCKED nunca; APPROVED bloqueado para edición                                                                                     | `admin-review` · `admin-bulk`                              |
| Autorización de precios sin dueño     | Sin action; capacidad no otorgada; botón deshabilitado con razón                                                                                                                    | `admin-safety` · `review.test`                             |
| Auditoría incompleta                  | `review_event` y `review_bulk_operation` append-only (triggers); `change_event` con actor/contexto                                                                                  | `admin-review` · `admin-bulk` · `admin-catalog`            |

## Actor local

No hay autenticación empresarial en STEP 06. `getActor()` toma `DTG_ADMIN_ACTOR` del entorno o, si no existe, el nombre escrito en la cabecera (cookie `httpOnly`, `sameSite=strict`, ruta `/admin`). **Sin actor no hay mutaciones.** El nombre es contexto de auditoría, no una identidad verificada: el Admin es una herramienta local y no debe exponerse a una red sin autenticación (fuera de alcance, P1-06).
